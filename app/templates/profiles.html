How profiles work

A profile bundles a node + DNS preset + route preset into one click.
Activating a profile deploys that config through the full pipeline (validate → deploy → restart → health check).
Settings and the active node update atomically — no separate steps needed.
Switching via Nodes or changing Settings manually moves you off-profile.
